---

# Коллекции

Коллекция — это набор объектов, сгруппированных вместе.

Связанные данные могут обрабатываться более эффективно, если они объединены в коллекцию, потому что вместо написания кода для каждого отдельного объекта можно использовать один и тот же код для обработки всех элементов коллекции.

Наиболее распространённые виды коллекций данных:

* хэш-таблицы;
* очереди;
* стеки;
* контейнеры;
* словари;
* списки.

---

# Класс `List<T>`

В лабораторной работе подробно рассматривается коллекция `List<T>` — типизированный список, используемый для хранения объектов выбранного типа.

## Общий формат создания списка

```csharp
List<ТипЭлементовСписка> ИмяСписка;

ИмяСписка = new List<ТипЭлементовСписка>();
```

---

# Особенности списков

Списки удобны тем, что:

* количество элементов заранее неизвестно;
* размер списка можно изменять во время работы программы;
* можно добавлять и удалять элементы динамически.

---

# Метод PrintElement()

```csharp
private void PrintElement()
{
    if ((current >= 0) &&
        (current < PhoneNote.Count))
    {
        Note MyRecord = PhoneNote[current];

        LastNameTextBox.Text =
            MyRecord.LastName;

        NameTextBox.Text =
            MyRecord.Name;

        PatronymicTextBox.Text =
            MyRecord.Patronymic;

        PhoneMaskedTextBox.Text =
            MyRecord.Phone;

        StreetTextBox.Text =
            MyRecord.Street;

        HouseNumericUpDown.Value =
            MyRecord.House;

        FlatNumericUpDown.Value =
            MyRecord.Flat;
    }
    else
    {
        LastNameTextBox.Text = "";

        NameTextBox.Text = "";

        PatronymicTextBox.Text = "";

        PhoneMaskedTextBox.Text = "";

        StreetTextBox.Text = "";

        HouseNumericUpDown.Value = 1;

        FlatNumericUpDown.Value = 1;
    }

    NumberToolStripStatusLabel.Text =
        (current + 1).ToString();

    QuantityToolStripStatusLabel.Text =
        PhoneNote.Count.ToString();
}
```

# Поиск по ФИО

```csharp
private void SearchButton_Click(
    object sender,
    EventArgs e)
{
    ResultsTextBox.Text = "";

    int i = 0;

    foreach (Note MyRecord in PhoneNote)
    {
        if (MyRecord.LastName.Contains(
                LastNameTextBox.Text)
            &&
            MyRecord.Name.Contains(
                NameTextBox.Text)
            &&
            MyRecord.Patronymic.Contains(
                PatronymicTextBox.Text))
        {
            i++;

            ResultsTextBox.Text =
                ResultsTextBox.Text
                + i.ToString()
                + ". "
                + MyRecord.LastName
                + " "
                + MyRecord.Name
                + " "
                + MyRecord.Patronymic;
        }
    }

    if (i == 0)
    {
        ResultsTextBox.Text =
            "Записей не найдено";
    }
}
```
